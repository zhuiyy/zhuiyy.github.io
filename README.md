# zhuiyy.github.io

Zhuiy 的个人主页：音乐、GEB、观星，以及一些正在发生的念头。

## 修改「最近在关注」

打开 `index.html`，搜索“最近关注”，直接修改紧随其后的四条文字即可。每条都有 `data-zh`（中文）、`data-en`（英文）和标签正文；标签正文与 `data-zh` 保持一致。

## 页面结构

- `index.html`：内容与链接
- `style.css`：视觉和响应式布局
- `script.js`：中英文翻面、动画、递归彩蛋和全球按钮
- `assets/origin.jpg`：头像

全球按钮使用公开计数服务同步总数；服务不可用时会自动在当前设备上继续计数。
